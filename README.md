# Satvik Gajula Portfolio

Static HTML portfolio ready for Vercel deployment.

## Deploy on Vercel
1. Upload this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep Framework Preset as **Other**; leave Build Command and Output Directory empty/default for this static site.
4. Deploy.

The resume PDF is stored at `resume.pdf`; both portfolio download links point to `/resume.pdf`.

Before publishing, replace the placeholder GitHub profile link (`https://github.com`) with your actual GitHub profile.
